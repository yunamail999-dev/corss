# Yunamail的棋盤 - 中國象棋（大盤 & 小盤暗棋）雙模式對弈平台

一個兼具東方古典美學、現代流暢動效與智慧 AI 決策引擎的高質感中國象棋 Web 對弈遊戲。支援**傳統大盤（9x10）**與**台灣特色小盤暗棋（4x8 連吃模式）**雙玩法，並針對桌機、平板與折疊手機（如 Samsung Galaxy Z Fold 7）進行了全方位的 RWD 響應式佈局適配。

---

## 🌟 核心特色

### 1. 雙對弈模式
- **傳統大盤（9x10）**：
  - 完整支援中國象棋正規競賽規則（拐馬腳、塞象眼、九宮格、楚河漢界、將帥不照面）。
  - 將軍偵測、將死與困斃判定。
  - **智慧 AI 大師開局庫**：收錄屏風馬、順手炮、列手炮、反宮馬、卒底炮、挺卒局等多樣化經典開局體系，徹底杜絕千篇一律的走法。
  - 具備防俗手戰略評估與 Alpha-Beta 剪枝近似最優步隨機採樣，對弈靈活多變。

- **小盤暗棋（4x8）**：
  - 32 顆棋子隨機覆蓋佈局，首翻決定陣營（紅先黑後）。
  - 正統位階吃子規則（帥>仕>相>俥>傌>包>兵、卒吃帥、包隔子跳吃）。
  - **特色「連吃模式」**：支援連續吃子玩法，提供清晰的「斬獲棋子」飛升殘影動效、連吃計數爆擊徽章與即時戰報提示。
  - **踩雷自投羅網機制**：翻開未知暗棋時，若攻擊者位階低於翻出之敵棋或遭遇剋星，攻擊者當場陣亡；若翻出己方棋子則中斷連吃換邊，杜絕自相殘殺。

### 2. 極致視覺與聲學饗宴
- **實木溫潤質感**：盤面採用黃花梨雕木刻線設計，棋子為平整實木無凸起圓潤徽章，結合黑紅沉穩配色。
- **靈動互動動效**：落子水墨金色波紋、將軍硃砂紅危險脈衝呼吸光環、最新走子金色光圈動向指引。
- **純天然程序化音效**：透過 Web Audio API 實現硬木落子清脆叩擊聲、雙子相撞破擊聲、翻棋輕響與五音編鐘連吃升調泛音。

### 3. 多端極致響應式適配 (RWD)
- **桌面寬螢幕**：大氣寬敞，左盤右譜，資訊一覽無遺。
- **行動裝置與摺疊螢幕**：特別適配 Samsung Galaxy Z Fold 7 外屏（384x880 狹長屏）縱向抗衡流與內屏（816x960 展開屏）雙欄大氣佈局。
- 加入手勢與觸控優化，徹底消除行動瀏覽器 300ms 點擊延遲。

### 4. 戰報與個人化記憶
- **生涯戰報卡片**：即時統計勝、負、和局與最高連吃紀錄，支援本機持久化儲存。
- **偏好記憶**：自動記憶玩家選擇之 AI 難度（初學、進階、大師）、連吃開關與音效設定。

## 🚀 快速啟動

本專案為純前端原生架構（HTML5 + Vanilla CSS + ES Modules JavaScript），無需繁瑣的後端環境即可直接運行：

### 本地運行方式
使用任意靜態 HTTP 伺服器啟動，例如：

```bash
# 使用 Python 內建伺服器
python -m http.server 8080

# 或使用 Node.js http-server
npx http-server -p 8080
```

在瀏覽器中造訪 `http://localhost:8080/` 即可開始對弈！

```text
│   └── main.js           # 遊戲主控制器、事件監聽與動畫渲染
└── README.md             # 專案詳細說明文件
```
